# Road_To_Graph_Project
VMS Profiler — это система для сбора метрик производительности (CPU, память, сеть) в распределённой вычислительной среде с последующей оптимизацией размещения задач.

Система позволяет:
-  **Профилировать** загрузку каждого узла и ядра
-  **Измерять** потребление памяти и пропускную способность
-  **Мониторить** сетевой трафик между задачами
-  **Генерировать** отчёты для оптимизации графа задач
-  **Оптимизировать** размещение приложений по узлам
